# Лос-Город

Браузерная 3D-игра в стиле GTA: город 18×18 кварталов, три деревни, фермы, шахта, полиция с настоящим полем зрения, метро-интерьеры у всех заведений и парк «Ракета» с работающими аттракционами.

- `npm install` — зависимости
- `npm run dev` — игра локально (Vite)
- `npm run build` — сборка в `dist/`
- `npm run check:<имя>` — автопроверки (см. ниже)

## Автопроверки

Все проверки запускаются без браузера и падают с кодом 1, если что-то сломалось.

| скрипт | что проверяет |
| --- | --- |
| `check:keys` | раскладка клавиш: ни одна клавиша не занята двумя действиями |
| `check:world` | генерация мира: дороги без дублей, парк «Ракета» (2×2 квартала, аттракционы, пруд, отсутствие «стен из воздуха»), казино, бары, деревни |
| `check:terrain` | поверхности под ногами: асфальт в городе, газон между дорожками парка, вода в пруду, грунт на полях |
| `check:farm` | работа на ферме «Зорька» и агрохолдинге «Нива»: контора, комбайн, поле, животные не в стенах |
| `check:npc` | водители-НПС: красный свет, паника в перестрелку до ~100 км/ч и возврат к обычной езде |
| `check:rides` | аттракционы парка: модели собираются, крутятся, место пассажира не улетает и не проваливается |
| `check:police` | поле зрения полиции: сектор, дальность, перекрытие стенами |
| `check:interiors` | все интерьеры: спавн не в стене, выход и точки действий достижимы, свет есть, нет отрезанных комнат |
| `check:server` | диагностика сервера: различает «сервер жив», «туннель жив, а сервера за ним нет» и «туннель мёртв» |
| `check:version` | версия в `package.json` совпадает с верхней записью `CHANGELOG.md` и попадает в сборку |

## Версия и обновления

Версия игры видна внизу экрана: слева под HUD (`v0.4.0 · 19.11`, рядом — точное время сборки),
на стартовой заставке и в паузе → «Настройки». По клику на плашку открывается «Что нового»
(журнал `CHANGELOG.md`), так что каждое обновление отличимо от предыдущего.

Новая версия:

```bash
npm run bump        # 0.4.0 → 0.4.1
# допишите запись в CHANGELOG.md: «## 0.4.1 — 20.11.2026» и пункты списком
npm run build
```

`npm run bump:minor` / `bump:major` — для крупных изменений.

## Онлайн: как понять, что случилось

Сервер (Colab + ngrok) отдаёт две служебные ручки:

- `/version` → `{ ok, server: "los-gorod", build, version, uptime, online, time }`
- `/diag` → то же плюс `maintenance`, `admin`, `ws`

Клиент сам проверяет `/version`, прежде чем ругаться. Окно «Нет связи» больше не пишет
загадочное `HTTP 404`, а объясняет причину и даёт кнопку «🔍 Проверить снова»:

| что видно | что это значит | что делать |
| --- | --- | --- |
| «туннель отвечает, но сервера за ним нет (HTTP 404)» | Colab перезапустился, `server.js` не поднят | выполнить серверную ячейку в Colab |
| «туннель не отвечает» | ngrok отключён или Colab заснул | запустить ячейку, дождаться ссылки |
| «игровой сервер на связи · сборка …» | сервер жив, не удался только вход | нажать «Повторить вход» |

Быстрая ручная проверка: открыть `<адрес-туннеля>/version` в браузере. JSON — сервер жив,
страница ngrok или 404 — сервер надо перезапустить, затем «📡 Постоянная ссылка», чтобы
обновить `server/live.json` (клиенты подхватят новый адрес сами).

## Управление

Полный список — в игре по `F1` («Как играть?»). Кратко: `WASD` — ходьба, `Shift` — бег, `C` — присед, `E` — действие (в том числе посадка в транспорт и аттракционы), `Tab` — планшет, `T` — чат, `U` — музыка, `Esc` — пауза.
